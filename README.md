This repository hosts the personal academic website of **Anirban Saha Anik**, a Ph.D. student in Computer Science and Engineering at the University of North Texas and a Graduate Research Assistant in the Human-Centered Computing Lab.

His research focuses on trustworthy and human-centered language technologies, including retrieval-augmented generation, multi-agent systems, controllable text generation, knowledge graphs, health misinformation intervention, crisis communication, and large language model evaluation.

## Repository Structure

This repository contains the production-ready static website used by GitHub Pages.

- `index.html` — homepage
- `research/`, `publications/`, `experience/`, `news/`, and `contact/` — website pages
- `assets/` — compiled styles and scripts
- `images/` — profile and research figures
- `files/` — CV, résumé, poster, and other downloadable materials
- `.nojekyll` — ensures GitHub Pages serves all generated assets correctly
- `sitemap.xml` and `robots.txt` — search-engine discovery files

## Deployment

1. Extract the website ZIP.
2. Upload all extracted files and folders directly to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**.
4. Select the website branch and the **/(root)** folder.
5. Save and wait a few minutes for GitHub Pages to publish the update.

The `index.html` and `.nojekyll` files must remain at the repository root. Do not upload the ZIP itself or place the extracted website inside another folder.
