GITHUB PAGES UPLOAD INSTRUCTIONS

1. Open https://github.com/anirbansahaanik/anirbansahaanik.github.io
2. Open the Code tab and make sure you are on the branch used by GitHub Pages (usually main or master).
3. Delete the old website files from the repository root.
4. Extract this ZIP on your computer.
5. Upload ALL extracted files and folders directly to the repository root.
   Important: index.html, .nojekyll, assets, images, and the page folders must be at the repository root—not inside another folder.
6. Commit the changes.
7. In Settings > Pages, select Deploy from a branch and choose the same branch with the /(root) folder.
8. Wait a few minutes, then open https://anirbansahaanik.github.io/ and refresh the page.

If GitHub's web uploader hides .nojekyll, keep it in the extracted folder and upload using GitHub Desktop instead. This file is required for reliable asset loading.
